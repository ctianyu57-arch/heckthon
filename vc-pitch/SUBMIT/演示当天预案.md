# 演示当天预案 (Demo Day Playbook)

> 目标：**演示不因网络问题翻车**。三层保险，逐级降级，任何时候都有可演的东西。

---

## 一、实测数据（我这边的真实结果，不是估计）

| 测试 | 结果 |
|---|---|
| 连续 10 次请求 | **10/10 成功**，HTTP 200 |
| 5 个并发（模拟观众同时打开） | **5/5 成功**，2.7–3.8 秒 |
| 首字节时间 | **1.5–4.0 秒**（偏慢） |
| 整页传输 | 135 KB |
| 外部依赖 | **0 个**（无 CDN、无外部字体、无第三方脚本） |

**结论：能打开，但首字节 1.5–4 秒意味着“点开后有 2 秒左右的空白等待”。**
这不是故障，是网络延迟。演示时别在这 2 秒里说话，先说一句过渡词。

**但我不建议你只靠它。** 下面三个风险是真实存在的：

### 风险 1：链接必须完整，抄漏一个字符就打不开

我实测：去掉 sharecode 访问 → **HTTP 403，页面显示“链接不完整”**。

链接是：
```
https://seed-round-simulator.app.workbuddy.host/?sharecode=SE6MRGV37C
```

只要 `SE6MRGV37C` 这个码错一位，或者漏掉 `?`，就是 403。

**对策：不要手打、不要口头念。用二维码，或提前存成浏览器书签。**

### 风险 2：这是托管沙箱，不是生产级 CDN

它跑在 WorkBuddy 的应用托管环境里。**我没有它的 SLA 承诺**，不能保证演示场地的网络路径、也不能保证平台不重启。

### 风险 3：现场网络会影响的不只是页面，还有对话

页面本身加载后是自包含的。但下面两项**运行时依赖网络**：

| 功能 | 依赖 | 断网后 |
|---|---|---|
| 她说话（TTS） | **不需要网络**（系统本地合成） | ✅ 照常 |
| 你说话（语音识别·原生） | Chrome → Google | ❌ 失效 |
| 你说话（语音识别·上传） | SiliconFlow / OpenAI API | ❌ 失效 |
| 她的对话内容（LLM） | DeepSeek API | ⚠️ 自动降级到预置话术库，**流程仍走得完** |

**好消息**：TTS 是本地合成，断网也照样说话。**最坏情况下，你依然能演示“一个会说话的 VC + 完整四关 + 潜台词复盘”**——只是她的话术来自预置库，不是实时生成的。

## 二、三层保险

### Plan A · 线上链接（主用）

```
https://seed-round-simulator.app.workbuddy.host/?sharecode=SE6MRGV37C
```

**必做三件事：**

1. **提前 30 分钟打开一次**，让链接热起来（我已实测复访仍需 1.7 秒首字节，所以别指望缓存）
2. **当场不要刷新**。演示中刷新等于再等 2–3 秒，还会丢掉进度
3. **提前填好 API Key**（DeepSeek），并点一次 “Test connection” 确认绿了

> Key 存在浏览器 localStorage 里。只要用同一个浏览器、不清缓存，下次打开还在。

### Plan B · 本地服务（网络正常但平台出问题时）

双击 `vc-sim/START-VOICE-DEMO.cmd`（**必须在文件资源管理器里双击，不是在 WorkBuddy 产物卡片上点**）

- 会弹出黑色窗口，**别关它**
- 自动打开 Chrome 到 `http://127.0.0.1:8123/`
- `127.0.0.1` 属于安全上下文，**麦克风可用**
- 需要你本机联网（LLM 和语音识别仍要访问 API）

### Plan C · 离线文件（网络全断时）

双击 `vc-sim/演示离线版.html`

- **完全离线**，不依赖任何服务器、不依赖任何 CDN
- ✅ 完整四关、隐藏账本、画像推断、潜台词复盘、**她照样说话**（TTS 本地合成）
- ✅ 打字作答正常
- ❌ 语音识别不可用（file:// 下浏览器不给麦克风）
- ⚠️ 对话内容走预置话术库（没有 API 就降级）

**这是最坏情况下的底线演出**。虽然不能演示“AI 实时生成”，但产品的核心价值——**读人、分级施压、潜台词揭示**——全都在。
