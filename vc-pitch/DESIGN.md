# DESIGN.md — VC 首轮融资模拟器 · 参赛路演

> 路由判定：产品介绍 / 项目提案 → **不属于**学术、咨询、政务三类垂直场景 → 走**通用设计原则** + 本项目原创设计稿（universal-only）。
> 用户显式指令优先：全篇基调沿用产品自身的视觉语言（深色科技感 + #00D4FF）。

## 1. 画布与母版

**画布**：1280×720。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px（含上 padding 20px） | 主标题 36px bold，左对齐起点 x=64 |
| **B · 内容区** | 120–660px | 540px | 一切正文、图示、卡片；禁止挤占 A/C 区 |
| **C · 页脚条** | 660–720px | 60px（含下 padding 20px） | 左侧项目名「VC 首轮融资模拟器」+ 右侧页码 `NN / 15`，统一 14px，文本色 opacity 0.45 |
| **页面 padding** | 上下 20px、左右 64px | — | A/B/C 均在 padding 之内 |

封面 / 3 个章节扉页 / 结束页省略 C 区，采用自定义版式；其余 11 页严格复用本母版。

## 2. 颜色系统（4 hex）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **背景色** | `#0A0E14` | 全篇底色 |
| **面板色** | `#131A22` | 卡片、容器、色块 |
| **强调色** | `#00D4FF` | 仅用于视觉焦点：巨型数字、关键判断、核心标注、CTA |
| **文本主色** | `#E6EDF3` | 标题与正文；次级文本用 `opacity: 0.6`，页脚用 `opacity: 0.45` |

**色彩面积分配**（逐页声明见 §6 映射表）

| 色彩角色 | 常规页 | Hero 页 |
| :--- | :--- | :--- |
| 背景色 | ≤ 65% | ≤ 55% |
| 面板色 | ≤ 25% | ≤ 25% |
| 强调色 | ≤ 5% | 15–20% |
| 中性（文本） | 剩余 | 剩余 |

**色彩节奏**：第 4、9、10、13 页强调色提升至 15%（数据冲击 / 核心创新 / AI 论证 / 教学闭环），与其余页形成显著差异。

### 2.1 渐变与半透明策略

- 主渐变：`linear-gradient(135deg, #00D4FF 0%, #0A6E8A 100%)` —— 仅用于章节扉页的巨型编号描边与 Hero 页的光带。
- 面板半透明：`rgba(0,212,255,0.08)` —— 用于强调内容的底色衬垫（对话气泡、结论条）。
- 边框：`rgba(230,237,243,0.12)`，1px。
- 背景氛围：`rgba(0,212,255,0.06)` 大圆或斜向色带，`opacity` 0.3 以内，禁止干扰正文。

## 3. 字体系统

**字体家族（2 套）**
- 中文 / 正文：`思源黑体`（fallback `PingFang SC`, `Microsoft YaHei`）
- 数字 / 西文强调：`JetBrains Mono`（fallback `Space Grotesk`, `Menlo`）—— 用于巨型数字与代码感元素

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 72px | bold | 1.2 | 仅第 1 页 |
| 章节大字 | 64px | bold | 1.1 | 章节扉页、结束页 |
| **巨型数据 / 锚点** | **96–120px** | **bold** | **1.0** | 每页至少 1 个视觉锚点；用 JetBrains Mono |
| 页面主标题 | 36px | bold | 1.3 | A 区固定 |
| 卡片小标题 | 26px | 600 | 1.4 | 卡片头、栏目标题 |
| 正文 | 22px | regular | 1.5 | 段落 |
| 引文 / 对话 | 20px | regular | 1.55 | 引用、对话气泡 |
| 脚注 / 页码 | 14px | regular | 1.4 | C 区 |

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 图示数 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 主标题 + 副标 + 主视觉 | 20 | 1 | ≥ 35% |
| 目录 | 3 条目 + 引导句 | 80 | 0 | — |
| 内容页（单主题） | 标题 + 正文 + 主视觉 | 180 | 1 | ≥ 30% |
| 数据 / 图示页 | 标题 + 主图 + 洞察 | 80 | 1 | ≥ 50% |
| 章节扉页 | 章节大字 + 一句小标 | 30 | 1 | ≥ 40% |
| 结束页 | 收束金句 + 落款 | 20 | 0 | — |

- 常规内容页留白 ≤ 35%；封面 / 章节扉页 / 结束页允许 40–45%。
- 卡片填充率 ≥ 85%；高度 ≥ 380px 的卡片正文 ≥ 100 字；尾部元素用 `marginTop: auto` 锚定底部。
- 同行卡片的三段（标题 / 正文 / 尾部）在 y 轴等高对齐，误差 ≤ 16px。

## 5. 配图系统（本项目：全程结构化视觉）

**声明**：本主题为**抽象概念 + 产品机制 + 数据论证**，不含具象场景（无办公场景、无人物群像）。因此全篇使用**结构化视觉**（排版 / 巨型数字 / SVG 图示 / 界面模拟），不使用摄影或插画类图片——理由：结构化视觉对机制的表达更精准，且能保证全篇风格统一。

| 等级 | 本项目用法 | 出现位置 | 最小尺寸 |
| :--- | :--- | :--- | :--- |
| **L1 · 主视觉** | 巨型数字锚点 / 界面模拟块 / 对照结构 | 01, 04, 07, 09, 13, 15 | 占 B 区 ≥ 40% |
| **L2 · 支撑图** | 流程图、时间轴、对比结构 | 05, 08, 10, 11, 14 | ≥ 280×180 |
| **L3 · 母版徽标** | 左下角「VC SIM」几何标记，全篇位置一致 | 所有内容页 C 区左侧 | ≤ 64×64 |
