# 分阶段提示词清单（照抄改）

核心原则只有一条：**一次只让它做一件事，做完预览确认，再做下一件。**

千万别开头就说"给我做个网站"——它会生成一大坨你根本改不动的东西，然后你在第 10 天推倒重来。这是黑客松最常见的翻车方式。

---

## 阶段 0：先让它挑战你的想法

```
我有个黑客松想法：[一句话描述]。
请扮演挑剔的评委，用最尖锐的问题挑战它：
这个需求真实吗？AI 是必需的还是硬凑的？3 分钟内能演示清楚吗？
如果太散，给我 2 个收敛后的更小版本，并说明各自砍掉了什么。
```

## 阶段 1：生成 PRD

```
基于我们刚才讨论的结果，按 01-想法收敛与PRD模板.md 的格式，
帮我写一份完整 PRD。我不会填的地方，你给一个合理默认值，并标注【待确认】。
写完后先别写代码，等我确认。
```

## 阶段 2：只要静态骨架（不要任何功能）

```
按 PRD 生成一个纯静态 index.html，单文件，CSS 和 JS 内嵌。
只要页面结构和占位内容，不要接任何 AI、不要后端、不要数据库。
视觉风格：深色背景 + 白色文字 + #00D4FF 强调色。
完成后告诉我在浏览器里怎么预览，我要先确认版式。
```

## 阶段 3：视觉确认（你的强项，值得多花时间）

```
现在只调整视觉：[具体到某个元素，例如"首屏标题的字号和留白"]。
不要改动任何功能逻辑。
```

## 阶段 4：一个一个加功能

```
只实现【某一个具体功能】，其他部分完全保持不变。
例如：点击上传按钮后，把图片显示在预览区，暂时不做任何 AI 处理。
```

## 阶段 5：接 AI（务必带上兜底）

```
现在给【某一步】接入 AI 能力：输入是____，期望输出是____。
必须同时实现兜底：调用失败或超过 3 秒时，显示预置的示例结果，
页面不能报错、不能空白、不能卡死。
AI 输出用打字机效果逐字显示（既是效果，也能掩盖延迟）。
```

## 阶段 6：打磨动效

```
加入这些动效：卡片 spring 弹入、内容滑入、AI 输出逐字显示。
只加动效，不改逻辑。
```

## 阶段 7：部署上线

```
把当前项目发布成在线链接。发布后给我 URL，
并提醒我必须换一台设备（或用手机）验证能否正常打开。
```

---

## 万能咒语（不好用时贴在提示词末尾）

- 一次只改一个地方，改完告诉我改了哪几行
- 不要重写整个文件，只做最小改动
- 做不到就直接说做不到，不要假装完成
- 完成后告诉我怎么预览、怎么验证

---

## 演示前 24 小时保命清单

- [ ] 换一台电脑 / 用手机打开在线链接，确认能访问
- [ ] 关掉 WiFi 试一次，确认兜底数据顶得上、页面不崩
- [ ] 录一段 60 秒完整操作录屏，现场断网时直接放视频
- [ ] 把 PRD 第 0 节那句话背下来，开场 10 秒就要说
- [ ] 3 分钟演示脚本卡时间练 2 遍，超时比没做完更扣分
- [ ] 提前 1 天部署完，**最后一天别再改代码**
